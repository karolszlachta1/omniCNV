# Tests and synthetic data

> Note: This documentation was generated by AI.

## Purpose

The tests in this directory verify that the package can load expected file schemas,
install correctly, and execute basic synthetic-data code paths without raising
errors.

The synthetic datasets are **smoke and integration-test fixtures only**. They do
not validate scientific correctness, biological realism, CNV-detection accuracy,
segmentation accuracy, parameter calibration, or agreement with real sequencing
data. A successful test run means that the exercised code path completed and
produced structurally usable output; it is not evidence that the analysis result
is correct.

## Run the tests

From the repository root:

```shell
pip install -e ".[test]"
python -m pytest -q
```

The tests use the small committed fixtures in `tests/fixtures/synthetic/` and do
not require the large generated datasets.

## Generate WGS data

The generator uses hg38 chromosome sizes, randomly placed markers, non-overlapping
CNV truth intervals, and an `AB` normal background:

```shell
python tests/generate_synthetic_dataset.py \
  --output-dir tests/fixtures/generated_latest \
  --prefix hg38
```

The WGS output includes:

- `hg38.vcf` and `hg38_allele_counts.tsv`
- `markerslist.tsv`, `arms.tsv`, and `cyto.tsv`
- `hg38.config.ini`
- `cnv_truth.tsv`, containing the simulated regions and their CNV state and `k`

Generated directories matching `tests/fixtures/generated_*/` are ignored by Git.
They may be large and are intended for local inspection only.

## Generate RNA data

RNA generation is opt-in. It can reuse the exact CNV truth from a WGS dataset:

```shell
python tests/generate_synthetic_dataset.py \
  --rna \
  --truth-cnv tests/fixtures/generated_latest/cnv_truth.tsv \
  --output-dir tests/fixtures/generated_rna \
  --prefix hg38
```

The RNA files add a reference panel and gene counts. Reference abundances are
sampled from `10 ** uniform(1, 7)`. For a gene in a CNV state, the expected count
is scaled by the state-derived copy number and sampled with Gaussian noise. The
RNA simulation is likewise only a runtime and file-format exercise, not a test
of RNA quantification or CNV inference validity.

## Analyze generated data

Generated data can be passed to omniCNV manually. For WGS:

```shell
cd tests/fixtures/generated_latest
omniCNV -t wgs -v hg38.vcf -c hg38.config.ini -s hg38_analysis
```

For RNA:

```shell
cd tests/fixtures/generated_rna
omniCNV -t rna \
  -v hg38.vcf \
  -gc hg38_gene_counts.tsv \
  -rp hg38_reference_panel.tsv \
  -c hg38.config.ini \
  -s hg38_analysis
```

Analysis reports are written relative to the current working directory. Run the
command from the generated-data directory if the reports should remain beside the
inputs.
